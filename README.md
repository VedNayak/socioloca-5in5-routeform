# Routeform Logistics
A fictional premium logistics brand and five-page SocioLoca design concept. All routes, cargo scenarios, imagery and operational models are illustrative. No real freight services, offices or bookings are represented.

React / TypeScript / Vite / GSAP / Three.js. Local assets, dark-only design, accessible reduced-motion fallbacks, and a local-only quote workbench.

`npm ci` · `npm run dev` · `npm run build` · `npm run lint` · `npm run typecheck`. Deployment uses only the `socioloca-5in5-routeform` Worker. Never deploy to another showcase target.

Preview: https://socioloca-5in5-routeform.ved-593.workers.dev/

Quote workbench: /quote/ — live dimensional SVG, identical-piece volume and gross-weight calculation, transport-specific document checklist, five-step review and downloadable local brief. The form never transmits data.
